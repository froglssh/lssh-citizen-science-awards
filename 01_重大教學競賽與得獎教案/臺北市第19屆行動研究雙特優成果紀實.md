# 臺北市第 19 屆教育專業創新與行動研究雙特優成果紀實

## 原始文檔資訊
- **主管機關**：臺北市政府教育局
- **學術賽事**：臺北市第 19 屆中小學及幼兒園教育專業創新與行動研究（高中組）
- **官方文檔**：`file:///Users/froglssh/Library/CloudStorage/GoogleDrive-frog@lssh.tp.edu.tw/我的雲端硬碟/09課程發表/1公民科學家/培訓高中學生擔任生態保育研究志工(麗山高中).pdf`
- **獲獎雙項殊榮**：
  1. **教育專業經驗分享類**：《培訓高中學生擔任生態保育研究志工 建立服務學習新方向》—— **特優**。
  2. **教材教具實物展示類**：《12年國教彈性學習課程推廣教材 公民科學家培訓課程模組》—— **特優 / 入選決審**。

---

## 一、雙料特優獲獎之四大核心論述

麗山高中生物科在同屆評選中同時在「論文論述」與「實體教具」兩大類別雙雙登頂，其在評審委員答辯中展現的說服力在於：

```
┌────────────────────────────────────────────────────────┐
│             第 19 屆行動研究雙特優核心亮點              │
├───────────────┬────────────────────────────────────────┤
│ 1. 痛點洞察   │ 直指 12 年國教超額比序造成服務學習虛無化│
│ 2. 解決方案   │ 提出 80 小時五階段、長程培訓公民科學家模型│
│ 3. 實證數據   │ 橫跨 102~107 年數百名學生真實調查數據與成果│
│ 4. 推廣教材   │ 產出 3 套實體講義 + 1 數位光碟，隨取即用 │
└───────────────┴────────────────────────────────────────┘
```

## 二、官方發表與教育影響力延伸
- 本得獎成果獲選於臺北市教育專業創新成果發表會進行全市公開口頭發表。
- 奠定了麗山高中在臺北市乃至全國「環境教育、公民科學、彈性學習課程發展」的領導先驅地位。
