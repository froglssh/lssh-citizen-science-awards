# 麗山高中公民科學家 課程發表與得獎子知識庫 (LSSH Citizen Science Awards & Dissemination Sub-Wiki)

本儲存庫為**臺北市立麗山高級中學 生物科**「公民科學家（課程發表、競賽獲獎與推廣）」之專屬子知識庫。  
本子庫與「母庫（12生物營隊知識庫）」及「課程子庫（01專題教材/公民科學培訓課程）」構成麗山生物科完整的**三位一體知識網絡**。

本庫專門收錄並深度提煉：
1. **天下文化「未來教育 臺灣100」得獎教案**全文剖析與創新架構。
2. **2018 全國學校經營與教學創新 KDP 國際認證獎**（環保小尖兵培訓教學課程）。
3. **臺北市第 19 屆教育專業創新與行動研究雙特優成果**。
4. **教育部高中優質化成果嘉年華**三聯巨幅展覽海報（左、中、右）設計美學。
5. **106、107、108 歷年重大教學成果發表會**全景簡報與學生影像紀錄。
6. **臺北市優質學校評選（課程發展、教師教學、學生學習、資源統整）**之單項或整體申辦論述轉化。
